# CUDFIRM Default Template — Adapter 1

This compatibility adapter connects the normalized CUDFIRM CMS contract to the original public frontend without rewriting `js/script.js` or `css/styles.css`.

## Current scope

- About content mounts at `#tab20`.
- Contact content mounts at `#connect-content`.
- Existing tab routing, forms, Site Settings patching, and template interactions remain in the legacy frontend.

## Compatibility requirement

The mount elements are generated by `js/script.js`. The shared runtime waits for those elements before validating and rendering.

## Boundaries

The adapter does not query Supabase, authenticate users, submit forms, or implement dashboard/security logic.
