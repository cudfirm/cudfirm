## Resend e-mail bridge
`supabase/functions/send-email-resend` receives the existing e-mail webhook calls and sends them through Resend.
Set `MEMBER_EMAIL_WEBHOOK_URL` to that function's URL. Without a verified Resend domain, Resend only delivers to the account owner's own address (fine for admin notifications; client acknowledgements need a verified domain).
Registration: `update public.member_settings set enabled=true, public_registration=true where id=1;`
