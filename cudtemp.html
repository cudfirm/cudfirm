FAQ

Questions,
answered

Need a specific delivery answer? Contact CUDFIRM directly and receive guidance based on your website, template, and CMS requirements.

Can I start with a ready template?
+
Yes. CUDFIRM can connect a reusable CUDFIRM-owned template to the shared CMS core, then replace its default content and imagery with your approved business information.
Can CUDFIRM connect my existing template?
+
Yes. A client-supplied template is audited first, then mapped through an isolated adapter. The existing CMS, dashboard, authentication, RLS, backup, and security systems are preserved.
Will every client share the same database?
+
No. Each client delivery uses its own deployment and Supabase project, while the reusable CUDFIRM core and compatible template framework remain consistent across projects.
How are roles and permissions protected?
+
Viewer, Editor, Admin, and Super Admin permissions are enforced through PostgreSQL RLS and Storage policies. Hidden dashboard buttons are not treated as the security boundary.
What can the dashboard manage?
+
The dashboard manages public content, media, SEO, messages, subscribers, themes, maintenance, analytics, health checks, backups, activity records, and authorized user access.
Can optional member accounts be included?
+
Yes. Member Accounts is an optional extension module with separate member profiles, controlled registration, verification, invitations, account states, trusted server operations, and protected permissions.
